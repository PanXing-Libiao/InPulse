# ADR-086 审计日志固化操作人身份快照

- 状态：Accepted
- 日期：2026-10-20
- 2026-10-20 关联：项目动态的身份快照由 [ADR-087](ADR-087.md) 按同一口径扩展。
- 决策人：项目负责人（用户指示）与开发代理共同确认
- 关联：补充 [ADR-008](ADR-008.md) 的审计载荷字段说明、修订 [ADR-082](ADR-082.md) 的审计历史显示前提；沿用 [ADR-085](ADR-085.md) 的「历史审计不随实体删除」口径；新增迁移 `0050_audit_actor_snapshot.sql`

## 1. 背景

ADR-082 以墓碑化代替物理删除，并保留 `app.users` 行供历史外键引用。用户随后确认下一阶段要支持离职账号的物理删除。当前审计 `event_payload` 只保存 `actorType` / `actorId`，审计页通过实时用户目录解析姓名；一旦用户行被物理删除，历史审计的操作人姓名将无法从业务数据中恢复。

审计日志必须在用户生命周期结束后仍然自包含、可校验。不能让「删除账号」反向改变已经发生的事件。

## 2. 决策

1. 每次追加 `actorType = 'USER'` 的审计时，`PostgresAuditWritePort` 在同一 `TransactionContext` 内读取 `app.users` 当前的 `id` / `name` / `login_name`，并写入 `eventPayload.actorSnapshot = { id, name, loginName }`。
2. `actorType = 'SYSTEM'` 的事件固定写 `actorSnapshot: null`。
3. `actorType = 'USER'` 但 `actorId` 为空或用户行不存在时，审计写入 fail closed，调用方事务回滚；不得产生缺少操作人身份的新审计。
4. `actorSnapshot` 与 `action` / `actorType` / `actorId` 等字段一起并入完整 `eventPayload`，参与 RFC 8785 JCS 信封和 HMAC-SHA-256 计算。快照一旦写入不可通过后续更新改写；验证哈希时必须使用数据库中的原始载荷。
5. 迁移 `0050_audit_actor_snapshot.sql` 删除 `audit_logs_actor_id_users_id_fk`。`actor_id` 保留为历史坐标，`audit_logs_actor_check` 与 `(actor_id, occurred_at)` 索引继续生效；审计行不再要求当前存在对应用户行。
6. 审计读取接口的契约不变，快照随现有 `eventPayload` 返回；前端优先读取与 `actorId` 匹配的 `eventPayload.actorSnapshot.name`，其次登录名，最后才回退实时用户目录或「用户 #id」。
7. 目标对象的历史身份继续由各业务事件既有的 `before` / `after` 或平铺载荷保存；本 ADR 不新增第二套目标快照协议。

## 3. 历史数据与边界

- 本迁移不回填、不重算任何历史审计行；旧记录没有 `actorSnapshot` 时继续按实时用户目录展示。若旧记录对应的用户行已被物理删除，其操作人姓名无法从审计中恢复，这是迁移前数据的已知边界。
- 旧行的 `record_hash`、`prev_hash`、`sequence_no` 与链头完全不变；新行只是在既有 `eventPayload` 中增加字段，因此 `canonical_version = 'JCS-1'` 无需升级，链仍可连续验证。
- 本 ADR 只解除审计表到用户表的外键；用户物理删除及其余业务表引用由 [ADR-088](ADR-088.md) 另行实现，本文“不实现用户物理删除”的边界在 ADR-088 后不再适用。

## 4. 非目标

1. 不删除、改写或重新签名历史审计行。
2. 不改变审计路由、读取权限、游标、幂等或归档格式。
3. 不为旧审计伪造当时姓名，也不以「删除用户」覆盖操作人快照。
4. 不把 `actorSnapshot` 用于鉴权或成员关系判定；鉴权仍只使用实时用户 / Session 数据。

## 5. 验证

- 真实 PostgreSQL 集成：USER 审计的 `eventPayload.actorSnapshot` 与写入时 `app.users` 一致；SYSTEM 审计为 `null`；缺失用户时整笔事务失败。
- 物理删除测试操作人后，`audit_logs` 行、链头与快照仍保留且 `audit_reader` 可读；重建 HMAC 时包含快照。
- 迁移断言：用户外键已移除，`audit_logs_actor_check` 仍存在且已验证。
- Web 单测：快照姓名优先于实时目录；旧记录无快照时保持原有回退。
