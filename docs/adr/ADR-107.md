# ADR-107 Casdoor 导入按账号权限收窄并保留全部 Physical 实体组

- 状态：Accepted
- 日期：2026-10-29
- 决策人：项目负责人（用户指示）
- 关联：修订 [ADR-101](ADR-101.md) §2、§3 与 §5 中对候选账号群组的二次收窄；保持 [ADR-100](ADR-100.md) 的 Physical 组路径还原、身份映射与单事务导入，以及 [ADR-102](ADR-102.md) 的预览分类不变

## 1. 背景

ADR-101 让 CASDOOR_IMPORT_PERMISSION 同时承担两项职责：筛选可登录 InPulse 的候选账号，以及按同一 Permission scope 再次裁剪候选账号的组引用。

实际 Casdoor 中，账号可以通过 Permission 或 Role 的直接 users 授权获得应用登录权限，而账号所属的 Physical 实体组本身不在 Permission scope 内。此类账号会进入导入预览，但组引用被二次过滤后全部丢失，因而被错误显示为“未分类（无实体组）”。

用户要求：只要账号本身有权限登录 InPulse，预览和导入就应识别该账号关联的 Physical 实体组。

## 2. 决策

### 2.1 Permission 只决定候选账号

- CASDOOR_IMPORT_PERMISSION 继续通过 Permission 及其角色继承读取 groups 与 users。
- 账号只要直接命中 users，或任一所属组命中 groups，就进入导入候选范围。
- 未命中 Permission 的账号仍不进入预览，避免把无应用登录权限的账号批量带入平台。
- Permission 必须启用、effect 为 Allow、state 为 Approved；读取失败、跨 owner、空范围或数量超限仍按现有规则 503 fail closed。

### 2.2 候选账号的全部组引用进入 Physical 解析

- 候选账号一旦确定，不再把 user.groups 与 Permission scope 求交集。
- 系统收集全部候选账号的组引用，通过同一组织的群组目录还原完整路径，并只保留启用中的 Physical 组。
- 账号通过某个组获得登录权限时，其同时关联的其他 Physical 实体组也全部展示并导入；直接 users 授权的账号同样保留自己的 Physical 实体组。
- Virtual 组、停用组、已删除组以及目录中不存在的陈旧引用继续忽略；组元数据读取或路径校验失败继续整批 fail closed。
- 无有效 Physical 实体组的候选账号仍归入“未分类”。未分类不是组织行，也不授予任何权限。

### 2.3 权限与数据边界

- Casdoor Permission、Role、群组与应用授权只用于判断候选账号和生成组织归属参考，不映射为 InPulse 项目权限、组长或系统管理员权限。
- 实体组没有 InPulse 应用权限并不影响其作为组织元数据被导入；同时，导入该组织也不会反向赋予 Casdoor 登录权限。
- 身份映射、首管理员禁用、单事务写入、审计计数、CSRF、幂等和确认时重新读取目录的语义均不变。
- 不新增路由、数据库迁移、配置项或依赖；未配置 CASDOOR_IMPORT_PERMISSION 时行为保持不变。

## 3. 影响

- 通过直接用户授权登录的两个账号不再显示为“未分类（无实体组）”，预览会展示其启用中的 Physical 实体组。
- 管理员导入后，这些实体组按现有组织同步规则建立或复用 InPulse 组织，并把候选账号加入对应组织。
- 组织列表可能包含不直接授予 Casdoor 应用权限的实体组；它们是人员分类数据，不代表授权扩大。
- 管理员预览说明改为“按应用权限收窄候选账号，但保留每个候选账号关联的全部启用 Physical 实体组”。

## 4. 验证

- API 单元覆盖直接用户权限命中、群组权限命中、未授权账号排除，以及候选账号的非 scope Physical 组仍传给组织解析并进入最终预览。
- 现有 Physical / Virtual、父子路径收敛、身份映射、幂等、CSRF 与审计测试保持通过。
- 部署后使用真实 Casdoor 重新打开预览，确认直接授权账号显示其实体组，再执行导入 smoke。
- 真实 Casdoor 联调结果必须单独记录，不能以单元测试替代。

## 5. 非目标

- 不把所有组织账号都纳入候选范围；
- 不把 Casdoor Permission、Role 或群组映射为 InPulse 授权；
- 不自动停用、删除或重新启用平台账号；
- 不新增后台定时同步、Webhook 或全组织持续轮询；
- 不修改历史迁移或既有 ADR 的决策记录。
