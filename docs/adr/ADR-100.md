# ADR-100 成员与角色页取消未分类筛选页签

- 状态：Accepted
- 日期：2026-10-27
- 决策人：项目负责人（用户指示）
- 关联：修订 [ADR-098](ADR-098.md) §2.3 中“管理员成员页增加未分类标签”的展示条款；组织模型、SSO 对账与虚拟分类口径不变

## 1. 背景

ADR-098 在管理员“成员与角色”页增加了“未分类”页签，用于把无组织账号单独筛出。实际使用时，绝大多数账号没有 Casdoor 实体群组，“未分类”与“全部”的内容几乎完全重合，只是把成员列表切成两段。用户明确表示不需要特意分出来，要求去掉这个分类框。

## 2. 决策

1. 移除“成员与角色”组织筛选条上的“未分类”页签，以及它绑定的 `orgView` 取值和计数；无组织成员继续出现在“全部”中。
2. 行内“未分类”徽章、批量移出提示、普通成员空态与项目成员选择器文案保持不变；“未分类”仍是虚拟分类，不落库、不授予权限。
3. 组织页签仍只展示有成员的真实组织，“系统管理员”页签不变。

## 3. 影响

- 管理员不需要先切到一个与“全部”内容相同的分类；成员列表回到单一平铺视图。
- 不涉及路由、OpenAPI、生成客户端、数据库 Schema、迁移或权限矩阵。

## 4. 非目标

1. 不删除“未分类”概念本身，也不改 SSO 群组收敛、类型过滤与对账规则。
2. 不改真实组织标签、批量加入与移出流程。

## 5. 验证

- Web 单元：`AdminUsersPageView.test.tsx` 断言不再渲染“未分类”页签，无组织成员在“全部”中仍可见。
- Playwright：`admin-users.spec.ts` 移除页签断言，保留行内徽章与列对齐断言。
