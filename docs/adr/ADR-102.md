# ADR-102 Casdoor 导入无变化账号不刷新与分类筛选

- 状态：Accepted
- 日期：2026-10-27
- 决策人：项目负责人（用户指示）与开发代理共同确认
- 关联：修订 [ADR-100](ADR-100.md) §2.1、§2.3 与 §5 的预览分类和默认勾选口径；保持 ADR-101 的 Permission 候选范围不变

## 1. 背景

ADR-100 对所有 sso_subject 已命中的账号一律标记为“刷新”。正式目录首次导入后再打开预览，84 个已导入账号会全部被默认勾选并再次同步资料与组织，既增加误操作风险，也无法区分真正发生变化的一批账号。

## 2. 决策

- 预览动作增加 unchanged（无变化）。已绑定账号只有在以下任一差异存在时才标记为 refresh：
  - Casdoor DisplayName 与平台姓名不同；
  - Casdoor 邮箱可安全写入平台且与平台邮箱不同；
  - Casdoor 实体组集合与平台当前组织成员关系集合不同。
- 资料与实体组都一致时标记 unchanged；不影响创建、绑定和冲突跳过规则。
- 管理员弹窗新增可按动作分类筛选：全部、新建、绑定、刷新、无变化、跳过。
- 默认只勾选新建、绑定和刷新；无变化、跳过不可勾选。筛选后的全选只作用于当前筛选结果，并保留其他分类中已选账号。
- 弹窗头部补充正常内边距与分隔线，正文改为固定头部、可滚动列表的自适应布局，避免标题贴住左上角。
- 审计日志补充 admin.user.casdoorImport、auth.sso_organizations_synced 与 CASDOOR_ORGANIZATION 的中文展示；筛选和原始快照仍使用机器码。

## 3. 影响

- Casdoor 导入预览响应新增动作 unchanged 与对应计数；不新增路由、数据库迁移或依赖。
- 无变化账号不会默认进入导入请求；如果直接调用确认接口并显式传入其 ID，服务端仍按当前目录事实重新执行幂等映射，不依赖旧预览。
- 既有 ADR-100 的全量组织对账语义不变；本次只优化预览分类、默认选择和展示。

## 4. 验证

- API 单元覆盖资料无差异、资料有差异、组织有差异三种分类。
- 真实 PostgreSQL 集成覆盖重复预览全部无变化、数据集移除实体组后只有该账号刷新。
- Web 单元覆盖默认不勾选无变化账号、分类筛选、当前筛选全选与审计中文标签。
